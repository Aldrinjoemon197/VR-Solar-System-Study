This file lists every file and folder that is actually committed to this
repository, for reference if something looks missing or out of place
after cloning. It excludes Unity's own generated cache folders (Library/,
Temp/, UserSettings/), which get rebuilt automatically and are not part
of the project.

Note: a few local-only files exist on team members' machines but are
deliberately NOT committed here and so are not listed below:
  - References/          raw source papers cited in the report (large,
                         third-party PDFs; full citation info is already
                         in VR_Solar_System_Report.bib)
  - the example report PDF and the project PPTX used for early planning
  - personal working notes

Key locations:
  VR Solar System/                        <- the actual Unity project (open THIS folder in Unity Hub)
  VR Solar System/Assets/                 <- all game scripts, scenes, and assets
  VR Solar System/Assets/Solar system backup 2.unity   <- the main scene to open
  README.md                               <- setup and run instructions
  VR_Solar_System_Report.tex / .bib       <- the written project report (LaTeX)
  vgtc.cls, abbrv-doi*.bst, diamondrule.*  <- the VGTC/TVCG template files needed to compile the report
  figs/                                   <- screenshots/images used in the report

asset, which is not included in this file listing since it is not part
